EloyTV review instructions

No EloyTV account, payment, subscription or geographical restriction is required. All Premium features are free in this beta. The app does not supply TV channels.

  1. Choose Russian or English on first launch.
  2. Open Playlists and add a playlist using the generic M3U provider.
  3. Name it Demo. Enter this URL: https://klim-sw.github.io/eloytv-site/review/demo.m3u
  4. Save, open the guide and select a test channel to play.
  5. If a guide source needs to be added separately, use https://klim-sw.github.io/eloytv-site/review/guide.xml.

The three channels are synthetic fixtures using our generated 30-second test-pattern clip with a tone. They are not real TV broadcasts. Replay the clip to repeat playback or recording checks. Archive playback requires a source with archive support and is not provided by this fixture.

Favourites, categories, reminders, playback controls and recording can be tested with the fixture. Parental PIN starts disabled; reviewers can choose their own PIN in Settings and save the recovery code shown during setup.
